## 🚀 快速开始

### 1. 安装Node.js

如果还没有安装Node.js，请先安装：
- 官网下载：https://nodejs.org/
- 推荐版本：LTS（长期支持版）

验证安装：
```bash
node --version
npm --version
```

### 2. 安装依赖

在 `web` 目录下运行：
```bash
npm install
```

这会安装以下依赖：
- `express` - Web服务器框架
- `axios` - HTTP客户端（用于代理请求）
- `nodemon` - 开发工具（可选，自动重启）

### 3. 配置ESP32 IP地址

**方法1：修改server.js文件**
```javascript
const ESP32_IP = '10.212.215.31';  // 改为你的ESP32 IP
```

**方法2：使用环境变量（推荐）**
```bash
# Windows CMD
set ESP32_IP=10.212.215.31 && npm start

# Windows PowerShell
$env:ESP32_IP="10.212.215.31"; npm start

# Linux/Mac
ESP32_IP=10.212.215.31 npm start
```

### 4. 启动服务器

```bash
npm start
```

看到以下输出说明启动成功：
```
========================================
✅ 服务器启动成功！
========================================
🌐 本地访问: http://localhost:3000
🌐 局域网访问: http://[你的电脑IP]:3000

📡 ESP32地址: 10.212.215.31
========================================
```

### 5. 访问控制面板

在浏览器中打开：
- **本地访问：** http://localhost:3000
- **局域网访问：** http://192.168.1.xxx:3000（替换为你的电脑IP）

## 🔧 功能说明

### 解决的问题

1. **CORS跨域问题** ✅
   - 浏览器直接访问ESP32会被CORS策略阻止
   - Node.js服务器作为代理，转发请求到ESP32
   - 完美解决跨域问题

2. **文件分离** ✅
   - HTML、CSS、JS分离，便于维护
   - 代码结构清晰，易于扩展

3. **开发体验** ✅
   - 使用nodemon自动重启（开发模式）
   - 详细的日志输出
   - 错误提示友好

### 工作原理

```
浏览器 → Node.js服务器 → ESP32
       ← (代理转发)    ←
```

1. 浏览器访问 `http://localhost:3000`
2. 前端发送请求到 `/api/status`
3. Node.js服务器转发到 `http://10.212.215.31/status`
4. ESP32响应数据
5. Node.js服务器返回给浏览器

## 🐛 常见问题

### Q1: npm install 失败
**A:** 尝试使用国内镜像：
```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### Q2: 端口被占用
**A:** 修改 `server.js` 中的 `PORT` 为其他值（如8080）

### Q3: 无法连接到ESP32
**A:** 检查：
1. ESP32是否在线（串口日志）
2. IP地址是否正确
3. 电脑和ESP32是否在同一WiFi
4. 防火墙是否阻止

### Q4: 显示"离线"
**A:** 
1. 检查ESP32 IP地址是否正确
2. 查看Node.js服务器日志
3. 确认ESP32的Web服务器正常运行

### Q5: 手机无法访问
**A:**
1. 确认手机和电脑在同一WiFi
2. 检查电脑防火墙设置
3. 尝试关闭电脑防火墙测试
